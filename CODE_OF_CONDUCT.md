# Code of Conduct

Be decent. This project is about treating people you interview with respect, so
it would be odd to run the project any other way.

Concretely: assume good faith, criticise the code rather than the person, and
accept that a maintainer saying "not this one" is an answer rather than an
opening position.

Harassment, personal attacks and deliberately wasting people's time are not
welcome and will get you blocked without much ceremony.

Report anything that needs reporting to rod.lunt@me.com.
